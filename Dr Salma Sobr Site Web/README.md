# Dr Salma Sobh — Site de démonstration

Maquette de démonstration commerciale (fichier HTML autonome, un seul fichier
`index.html` avec CSS et JS inline, image du cabinet en base64) pour
Dr Salma Sobh, chirurgien-dentiste orthodontiste à Aïn Chock, Casablanca.

**Statut** : maquette commerciale, pas un site de production.
- Aucun backend, aucune base de données, aucun vrai système de réservation.
- Le calendrier de prise de RDV est factice (démo visuelle uniquement).
- Les horaires affichés sont un placeholder non vérifié par la praticienne.
- Le texte de la politique de cookies est un placeholder générique à faire
  valider par un professionnel avant toute mise en ligne réelle.

Toutes les autres informations (adresse, téléphones, diplômes,
certifications, services) sont des données réelles vérifiées.
